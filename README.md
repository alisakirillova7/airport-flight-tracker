Суть приложения: Система для управления и отслеживания рейсов аэропорта (учет пассажиров, билетов, самолетов и расписания).

Стек технологий: Java, Jmix 2.x, PostgreSQL/Liquibase, Gradle, Git.

Ключевой функционал: Настройка сущностей и связей, валидация дат вылета (FlightDatesValidator), слушатели событий (PassengerEventListener) и гибкое разграничение ролей доступа.
